## Stack

HTML5 + CSS3 + JS ES Modules (sin frameworks, sin npm).
Firebase Firestore (RSVP) · GitHub Pages (hosting) · lottie-web (animaciones).

## Desarrollo local

No requiere instalación. Servir la carpeta con cualquier servidor estático:

```bash
# opción 1
npx serve .

# opción 2 (Python)
python3 -m http.server 8080
```

Abrir `http://localhost:8080` (los ES Modules no funcionan con `file://`).
